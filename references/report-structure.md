# Standard Report Structure

## Full Report Template

Every brand market insight report must follow this structure:

```markdown
# [Category/Brand] Market Insight Report
## Executive Summary
## Key Findings at a Glance

---

## 1. Market Overview
### 1.1 Market Size and Growth
### 1.2 Category Lifecycle Stage
### 1.3 Regional Variance Analysis
### 1.4 Regulatory Environment

## 2. Competitive Landscape
### 2.1 Competitor Identification
### 2.2 Competitor Matrix (Price Band × Positioning)
### 2.3 Top 5 Competitor Deep Dives
### 2.4 SWOT Summary

## 3. Consumer Profiling
### 3.1 Demographics
### 3.2 Consumption Behavior and Usage Scenarios
### 3.3 Content Preferences and Key Touchpoints
### 3.4 Purchase Decision Journey

## 4. Channel Analysis
### 4.1 Channel Structure Overview
### 4.2 Core Platform Strategy
### 4.3 Channel ROI Assessment

## 5. Trends and Opportunities
### 5.1 Macro Consumer Trends
### 5.2 Category Innovation Direction
### 5.3 Potential Risks and Mitigation

## 6. Brand Strategy Recommendations
### 6.1 Positioning Recommendation
### 6.2 Product Strategy
### 6.3 Channel Strategy
### 6.4 Marketing Strategy
### 6.5 Risk Mitigation

## Appendix
### A. Data Sources and Methodology
### B. Competitor List
### C. Glossary of Key Terms
### D. Disclaimer
```

## Section Requirements

### Executive Summary (300 words max)
- ONE paragraph summarizing: market opportunity size, competitive gap, target consumer insight, recommended entry strategy
- Must be standalone readable
- CN language

### Key Findings at a Glance
- 5-row table: Dimension | Key Finding | Confidence | Implication

### 1. Market Overview
- Market size in USD/RMB with CAGR
- TAM/SAM/SOM calculation when entering a new market
- Category lifecycle stage with evidence
- Regional breakdown if multi-country analysis
- Table: Region | Market Size | YoY Growth | Key Characteristics

### 2. Competitive Landscape
- Direct + indirect + emerging competitors identified
- Competitor matrix table (minimum 8 competitors)
- Top 5 depth: positioning, products, pricing, channels, marketing, social media
- SWOT summary table
- Competitive positioning map description (price band × positioning)

### 3. Consumer Profiling
- Demographics table
- Behavioral insights with usage scenarios
- Content preference breakdown by platform
- Decision journey mapped with touchpoints and conversion barriers

### 4. Channel Analysis
- Channel structure table with online/offline split
- Platform comparison table for key channels
- ROI assessment with qualitative or quantitative data

### 5. Trends and Opportunities
- 3-5 macro trends with impact assessment
- Innovation direction with examples
- PEST summary table
- Risk matrix: Risk | Likelihood | Impact | Mitigation

### 6. Brand Strategy Recommendations
- Clear positioning statement
- Product strategy: price band, hero SKU, innovation pipeline
- Channel strategy: priority channels, entry sequence, partnership model
- Marketing strategy: content approach, KOL tiers, budget allocation guidance
- Risk mitigation for each identified risk

### Appendix
- All data sources listed with URL or document reference
- Complete competitor list with basic info
- Glossary of key metrics and terms
- Standard disclaimer

## Variable Report Types

### Quick Competitor Scan (when user requests brief overview)
Output Sections: Executive Summary → Competitor Matrix → Top 3 Depth → Key Takeaways
Word count: ~1500

### Market Entry Assessment (when user requests market entry evaluation)
Output Sections: Executive Summary → Market Overview → Competitive Landscape → Consumer Profile → Channel Analysis → Strategy Recommendations
Word count: ~5000

### Consumer Deep Dive (when user requests consumer research)
Output Sections: Executive Summary → Demographics → Behavior → Content & Media → Decision Journey → Implications
Word count: ~3000

### Full Report (default)
All sections as per full template
Word count: ~8000
